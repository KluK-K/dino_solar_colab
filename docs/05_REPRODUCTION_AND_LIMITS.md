## A recipient can do this now

1. Read the article and result tables.
2. Inspect exact frozen model/training/statistics source.
3. Run python3 tools/verify_package.py with the Python standard library.

The checker verifies hashes, links, original bundle identity, coverage and selected summary values. It parses Python without executing research modules. It does not train, score, download inputs, run the scientific test suite or start automation.

Optional tools/build_reader_figures.py uses matplotlib to redraw the included aggregate figures from saved CSVs. It does not load models or raw data.

## Repeatability actually demonstrated

The unchanged original analyzer reproduced all 1,683 saved-job records and 6,212 contrasts, apart from generation time, on the **same host, environment, implementation and saved outputs**. Original analysis bytes remained unchanged.

This is not an independent implementation, fresh training/inference run, OS-isolation test, cross-device equivalence test or training-population reproduction.

Historical 171 original and separate 164 fresh-environment checks are same-host implementation/metadata/oracle checks. New package byte/AST/coverage checks are distinct from scientific performance replication.

## Limits to retain

- Intervals are fitted-system conditional and unadjusted across a large comparison family.
- Teachers, deterministic reuse, overlapping cohorts and endpoints are correlated.
- Matched annotations do not match pretraining, HPO, objectives or optimizer work.
- Both UCF and SCDD development informed design.
- PVEL lacks verified capture-family CIs; boxes cannot support Dice.
- Unsupported UCF normal-structure FPR and empty rates stay null.
- Physical modules, all cropped overlaps and pretraining membership remain unverified.
- No universal superiority, first-use novelty, guaranteed speed or operational reliability is claimed.

The separate 1 November course SVM holdout event changes no DINOv3 result. Authorship, correspondence and journal-specific finalization remain owner-deferred.
